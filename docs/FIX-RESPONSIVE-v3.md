# 📱 THE SHOP BD — মোবাইল রেসপনসিভ ফিক্স (v3)

## সমস্যা কী ছিল?

মোবাইলে সাইট খুললে **পুরো পেজ ডানে-বামে মুভ (স্ক্রল) করত** — কন্টেন্ট ডিসপ্লের সাথে ফিট হতো না।
স্ক্রিনশটে দেখা যাচ্ছিল:

- উপরের ঘোষণা বারের লেখা বাম দিকে কাটা ছিল
- হেডারের লোগো/মেনু বাম দিকে চাপা পড়ে ছিল
- হিরো ব্যানারের "THE SHOP BD" লেখার "T" কাটা
- ক্যাটাগরি টাইলের প্রথম কলাম বাম দিকে অর্ধেক দেখা যাচ্ছিল
- নিচের নেভিগেশনে লেবেল ওভারল্যাপ

## মূল কারণ (Root Cause)

পরীক্ষায় ধরা পড়েছে: **হেডারের লোগো বাটন সংকুচিত (shrink) হতে পারছিল না।**

```
হেডার রো (360px স্ক্রিনে):
[মেনু 36px] [লোগো 170px — shrink ব্লকড] [সার্চ+বেল+হার্ট+কার্ট 150px]
            ↑ min-width:auto এর কারণে ব্র্যান্ড নামের চেয়ে ছোট হতে পারে না
```

যোগফল = ৩৯৬px > ভিউপোর্ট ৩৬০px → ডকুমেন্ট প্রস্থ ভিউপোর্টের চেয়ে ৩৬px বড় হয়ে
যায় → **সম্পূর্ণ পেজ horizontal scroll করে** (প্রতিটা পেজে — হোম, শপ, কার্ট, চেকআউট সবখানে)।

## যা যা ঠিক করা হয়েছে (৩টি ফিক্স)

### ফিক্স ১ — হেডার লোগো বাটন সংকুচিত করার যোগ্য করা (মূল ফিক্স)
`src/components/store/header.tsx`

```tsx
// আগে: <button onClick={...} aria-label={...}>
// পরে:
<button ... className="min-w-0 shrink overflow-hidden text-left">
```

- `min-w-0` → বাটন এখন ব্র্যান্ড নামের min-content চেয়ে ছোট হতে পারে
- ভেতরের `Logo` কম্পোনেন্টে আগে থেকেই `truncate` ছিল — তাই নাম সুন্দরভাবে
  "THE S..." এলিপসিস হয়ে যায়, কোনো আইকন আর ভিউপোর্ট ছাড়ায় না
- বাড়তি স্ক্রিন-রুম পেলে লোগো আবার পুরো প্রস্থে দেখায় (স্বয়ংক্রিয়)

### ফিক্স ২ — গ্লোবাল horizontal overflow guard
`src/app/globals.css`

```css
html, body { overflow-x: clip; }
```

- ভবিষ্যতে যেকোনো কারণে (অ্যাডমিন-আপলোড করা লম্বা লিংক/ইমেজ, কাস্টম HTML ইত্যাদি)
  কোনো এলিমেন্ট ভিউপোর্ট ছাড়িয়ে গেলেও **পেজ আর ডানে-বামে মুভ করবে না**
- ইচ্ছাকৃতভাবে `hidden` নয়, `clip` ব্যবহার করা হয়েছে: `clip` scroll container
  তৈরি করে না, তাই **sticky হেডার ও ভেতরের horizontal স্ক্রলার** (ক্যাটাগরি গ্রিড,
  প্রোডাক্ট গ্যালারি ক্যারোসেল) স্বাভাবিক কাজ করে

### ফিক্স ৩ — বটম নেভিগেশন লেবেল hardening
`src/components/store/app-shell.tsx`

- প্রতিটি নেভ আইটেমে `min-w-0 px-0.5` + লেবেলে `w-full truncate text-center`
- খুব সরু স্ক্রিনেও (320px) লেবেল কখনো পাশের সেলে ব্লিড/ওভারল্যাপ করবে না

### ফিক্স ৪ — Service Worker ক্যাশ ভার্সন বাম্প
`public/sw.js`

```
tsb-v1 → tsb-v3
```

- নতুন বিল্ড ডিপ্লয় করলে পুরনো ভিজিটরের ব্রাউজার স্বয়ংক্রিয়ভাবে নতুন ভার্সন নেবে
  (পুরনো ক্যাশ শেল পেজ আর সার্ভ হবে না)
