## ধাপ ১ — দ্রুত বিক্রয় বাড়াবে (এক সপ্তাহের কাজ)

| # | ফিচার | কষ্ট | কেন দরকার |
|---|---|---|---|
| ১ | **PWA + Push Notification** | ⭐⭐ | কাস্টমার "Add to Home screen" করে অ্যাপের মতো ব্যবহার করবে; ডিসকাউন্ট নোটিফিকেশনে ফেরত আসবে |
| ২ | **WhatsApp অর্ডার বাটন + ফ্লোটিং চ্যাট** | ⭐ | বাংলাদেশে সবচেয়ে বেশি অর্ডার WhatsApp/Messenger-এই হয় |
| ৩ | **Google Analytics 4 ইভেন্ট + Facebook Pixel** | ⭐ | কে কী দেখে কিনল, কোন বিজ্ঞাপন কাজ করল — সব মাপা যাবে; রিমার্কেটিং শুরু করা যাবে |
| ৪ | **রিভিউতে ছবি আপলোড** | ⭐⭐ | ছবিসহ রিভিউ কনভার্সন ২–৩ গুণ বাড়ায় |
| ৫ | **স্টক শেষ প্রায় — জরুরি ব্যাজ + স্টক নোটিফিকেশন** | ⭐ | FOMO তৈরি করে দ্রুত সিদ্ধান্তে আনে |

**কীভাবে বসবে:**
- **PWA:** `public/manifest.webmanifest` আর আইকন **আগে থেকেই আছে** — শুধু `public/sw.js` (service worker) লিখে `src/components/store/app-shell.tsx`-এ রেজিস্টার করতে হবে। Push-এর জন্য Firebase Cloud Messaging (FCM) — ফ্রি। টোকেন RTDB-তে `fcmTokens/{uid}` নোডে রাখুন, অ্যাডমিন → মার্কেটিং → ব্রডকাস্ট থেকে পাঠান (আপনার broadcast-toaster.tsx এর সাথে জোড়া যাবে)।
- **WhatsApp:** `src/components/store/footer.tsx` + `product-detail-view.tsx`-এ ফ্লোটিং বাটন: `https://wa.me/8801XXXXXXXXX?text=আমি অর্ডার করতে চাই: {প্রোডাক্ট URL}`। নাম্বারটা সেটিংসে যোগ করুন (`site-settings.ts`)।
- **GA4/Pixel:** আপনার Firebase config-এ `measurementId` **আগে থেকেই আছে** — `firebase/analytics` ইনিশিয়ালাইজ করে `view_item`, `add_to_cart`, `purchase` ইভেন্ট পাঠান (`use-cart.ts` ও `checkout-view.tsx`-এ হুক বসবে)। Facebook Pixel: অ্যাডমিন সেটিংসে Pixel ID ফিল্ড + layout.tsx-এ স্ক্রিপ্ট।
- **রিভিউ ছবি:** `reviews` ডেটা-তে `images: []` ফিল্ড + আপনার GitHub মিডিয়া হোস্টিং আপলোডার (`lib/db/github.ts`) পুনঃব্যবহার।

## ধাপ ২ — কাজ অটোমেট করবে (মালিকের সময় বাঁচাবে)

| # | ফিচার | কষ্ট | কেন দরকার |
|---|---|---|---|
| ৬ | **SMS নোটিফিকেশন** (অর্ডার কনফার্ম, স্ট্যাটাস পরিবর্তন) | ⭐⭐ | ফোন-ভিত্তিক বাংলাদেশি কাস্টমারের কাছে SMS-ই সবচেয়ে বিশ্বস্ত |
| ৭ | **অনলাইন পেমেন্ট গেটওয়ে (bKash API / SSLCommerz / ShurjoPay)** | ⭐⭐⭐ | TrxID ম্যানুয়াল ম্যাচ করা থেকে মুক্তি — পেমেন্ট অটো ভেরিফাই |
| ৮ | **কুরিয়ার API (Pathao / Steadfast / RedX)** | ⭐⭐ | অ্যাডমিন থেকে এক ক্লিকে কনসাইনমেন্ট তৈরি + ট্র্যাকিং অটো-সিঙ্ক |
| ৯ | **ইনভয়েস PDF ডাউনলোড + বারকোড লেবেল প্রিন্ট** | ⭐⭐ | প্যাকেজিং ও হিসাবের কাজ অর্ধেক |
| ১০ | **Google Sheets-এ অর্ডার অটো-সিঙ্ক** | ⭐ | অ্যাকাউন্টস/স্টাফ দল শিটেই কাজ করতে পারবে |
| ১১ | **লো-স্টক অ্যালার্ট (ইমেইল/নোটিফিকেশন)** | ⭐ | স্টক শেষ হয়ে বিক্রয় হারানো বন্ধ |

**কীভাবে বসবে:**
- **SMS:** Bulk SMS Bangladesh / SSL Wireless / SMSBDAPI — যেকোনো একটার API (প্রতি SMS ~০.৩০–০.৪০৳)। Next.js-এর API route (`src/app/api/sms/route.ts`) বানিয়ে সেখান থেকে কল করবেন (API key ব্রাউজারে দেখাবে না)। ট্রিগার: অর্ডার তৈরি ও স্ট্যাটাস আপডেটের জায়গায় (`admin-orders.tsx` + `checkout-view.tsx`)।
- **পেমেন্ট গেটওয়ে:** শুরুতে **SSLCommerz** সবচেয়ে সহজ (bKash/Nagad/কার্ড সব একসাথে, ডকুমেন্টেশন ভালো)। ফ্লো: checkout → SSLCommerz হোস্টেড পেজ → success callback-এ অর্ডার `paid`। আপনার `admin-payments.tsx`-এ আগেই ট্রানজেকশন ভেরিফিকেশন UI আছে — অটো-ভেরিফাইড মার্ক যোগ হবে। bKash Tokenized Checkout চাইলে তার পরে। (⚠ এগুলোতে ব্যবসায়িক TIN/ট্রেড লাইসেন্স লাগে।)
- **কুরিয়ার:** Pathao Courier API — অর্ডার ভিউতে "Send to Pathao" বাটন → API কল → consignment_id ও track URL অর্ডারে সেভ। আপনার delivery/কুরিয়ার মডিউলের সাথে সরাসরি মেলে।
- **PDF:** ইনভয়েস পেজে প্রিন্ট স্টাইল আগেই আছে — `jspdf` + `html2canvas` লাইব্রেরি দিয়ে "PDF ডাউনলোড" বাটন যোগ করলেই হবে। বারকোড: `jsbarcode`।

## আমার সাজেস্টেড ক্রম (বাস্তবসম্মত প্ল্যান)

```
সপ্তাহ ১     → ২ (WhatsApp) + ৩ (GA4/Pixel) + ৫ (স্টক ব্যাজ)     [সব ফ্রি]
সপ্তাহ ২     → ১ (PWA + Push) + ১১ (লো-স্টক অ্যালার্ট)
মাস ২        → ৬ (SMS) + ৯ (PDF/বারকোড) + ৪ (রিভিউ ছবি)
মাস ৩        → ৮ (কুরিয়ার API) + ১২ (লয়ালটি) + ১৪ (অ্যাব্যান্ডন্ড কার্ট)
```

## টেকনিক্যাল নোট (কোড এডিট করার আগে)

1. **কোথায় কী:** UI → `src/components/store/`, ডেটা/লজিক → `src/lib/db/`, সেটিংস স্কিমা → `src/lib/site-settings.ts`, নেভিগেশন → `src/lib/nav.ts`, অ্যাডমিন সেকশন রেজিস্ট্রি → `src/components/store/admin/sections.ts` + `admin-app.tsx`।
2. **নতুন RTDB নোড** যোগ করলে `database.rules.json` আপডেট করে Console-এ Publish করতে ভুলবেন না।
3. **API key কখনো ক্লায়েন্ট-সাইডে নয়** — Next.js API route বানিয়ে সার্ভার থেকে কল করুন।
4. **প্রতিটা ফিচারের পরে:** `npm run build` দিয়ে টেস্ট → অ্যাডমিন → ব্যাকআপ → JSON এক্সপোর্ট নিয়ে রাখুন।
5. বিস্তারিত ভবিষ্যৎ-ব্যাকএন্ড পরিকল্নন: `docs/FUTURE-BACKEND.md` দেখুন।
