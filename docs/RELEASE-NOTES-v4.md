## ২) অ্যাডমিন প্যানেল নিয়ন্ত্রণ

**কোথায়:** অ্যাডমিন প্যানেল → হোমপেজ কনটেন্ট → **"পার্ক বক্স"** ট্যাব

### যা যা করা যায়:

1. **নতুন ব্যাজ যোগ** — "নতুন ব্যাজ" বাটনে ক্লিক করুন
2. **এডিট** — যেকোনো ব্যাজের পাশের ✏️ বাটন
3. **মুছে ফেলা** — 🗑️ বাটন (কনফার্মেশন ডায়ালগসহ)
4. **সক্রিয়/নিষ্ক্রিয়** — প্রতিটি ব্যাজের সুইচ (নিষ্ক্রিয় = সাইটে দেখাবে না)
5. **সর্ট অর্ডার** — সংখ্যা ছোট হলে আগে দেখাবে
6. **মাস্টার সুইচ** — "সেকশন চালু/বন্ধ" — পুরো সেকশন পণ্য পেজ থেকে লুকান
7. **লাইভ প্রিভিউ** — অ্যাডমিনে পরিবর্তনের সাথে সাথে পণ্য পেজের মতো দেখা যায়

### প্রতিটি ব্যাজের ফিল্ড:

- **আইকন** — ২১টি আইকন থেকে বাছুন (ট্রাক, শিল্ড, রিটার্ন-অ্যারো, হেডসেট, ক্যাশ...)
- **শিরোনাম** (আবশ্যক) — যেমন: দ্রুত ডেলিভারি
- **সাবটাইটেল** (ঐচ্ছিক) — যেমন: ২৪-৭২ ঘন্টায়

### ডিফল্ট ৩টি ব্যাজ:

| আইকন | শিরোনাম | সাবটাইটেল |
|---|---|---|
| 🚚 bi-truck | দ্রুত ডেলিভারি | ২৪-৭২ ঘন্টায় |
| 🛡️ bi-shield-check | ১০০% অরিজিনাল | নিশ্চয়তা |
| 🔄 bi-arrow-counterclockwise | সহজ রিটার্ন | ১২ ঘন্টায় |

## ৩) মোবাইল হেডার ফিক্স

- **আগে:** মোবাইলে হেডারে লোগো + টাইটেল + সাবটাইটেল তিনটাই থাকত —
  জায়গা কমে অ্যাকশন বাটনগুলো স্ক্রিনের বাইরে চলে যেত এবং পুরো পেজ
  ডানে-বামে মোভ করত (horizontal overflow ~৬px)।
- **এখন:** মোবাইল ভিউতে শুধু **লোগো** দেখাবে; টাইটেল + সাবটাইটেল `sm`
  ব্রেকপয়েন্ট (≥৬৪০px) থেকে দেখা যাবে। ডেস্কটপ সম্পূর্ণ অপরিবর্তিত।
- ব্রাউজার টেস্টে যাচাই: মোবাইল ৩৯০px ভিউয়ে পেজ overflow = **০px**।

## ৪) টেকনিক্যাল ডিটেইল (ডেভেলপারদের জন্য)

- **নতুন RTDB কালেকশন:** `shop/productPerks` — টাইপ `ProductPerk`
  `{ id, icon, title, subtitle, active, sortOrder }`
- **নতুন সেটিংস কী:** `pd_perks_enabled` (`'1'` = দেখাবে, `'0'` = লুকাবে)
- **ফাইল পরিবর্তন:**
  - `src/lib/db/types.ts` — ProductPerk টাইপ + DBData + SiteSettings
  - `src/lib/db/seed-data.ts` — productPerksSeed + ডিফল্ট সেটিংস
  - `src/lib/site-settings.ts` — PUBLIC_KEYS-এ নতুন কী
  - `src/lib/db/core.ts` — ভার্সন-আপগ্রেড contentKeys
  - `src/lib/db/services.ts` — productPerksList()
  - `src/lib/icons.tsx` — bi-arrow-counterclockwise পিকারে যোগ
  - `src/components/store/product-detail-view.tsx` — নতুন ডিজাইন রেন্ডার
  - `src/components/store/admin/admin-content.tsx` — PerkBoxManager + ট্যাব
  - `src/components/store/logo.tsx` — মোবাইলে শুধু লোগো

### মাইগ্রেশন (গুরুত্বপূর্ণ):

আপনার লাইভ RTDB-তে নতুন কালেকশন/সেটিংস না থাকলেও **কিছু করতে হবে না**:
- `productPerks` না থাকলে ডিফল্ট ৩টি ব্যাজ অটো-সিড হবে
- `pd_perks_enabled` না থাকলে সেকশন চালু (default '1') ধরা হবে
- অ্যাডমিন প্যানেলে প্রথম পরিবর্তনেই সব ডেটা RTDB-তে সেভ হয়ে যাবে
