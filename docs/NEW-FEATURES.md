# 🚀 THE SHOP BD — নতুন ফিচার সেটআপ গাইড (v6)

এই ভার্সনে ১০টি নতুন ফিচার যোগ হয়েছে — সবগুলো **অ্যাডমিন প্যানেল থেকে সম্পূর্ণ কন্ট্রোলযোগ্য**। নিচে প্রতিটার সেটআপ ধাপ। যেকোনো সময়, যেকোনো ফিচার চালু/বন্ধ করতে পারবেন — কনফিগ না করা পর্যন্ত কিছুই কাস্টমারের সামনে দেখাবে না।

> ⚠️ **প্রথমে একবার (বাধ্যতামূলক):** Firebase Console → Realtime Database → Rules-এ নিচের রুলস পাবলিশ করুন (প্রজেক্টের `database.rules.json` ফাইলের কনটেন্ট — নতুন `webhooks` নোড যোগ হয়েছে):
>
> ```json
> {
>   "rules": {
>     ".read": false,
>     ".write": false,
>     "shop": { ".read": true, ".write": true },
>     "webhooks": { ".read": true, ".write": true }
>   }
> }
> ```

## ২. Google Analytics 4 + Facebook Pixel 📊

**অ্যাডমিন → ইন্টিগ্রেশন → GA4 ও পিক্সেল**

- **GA4:** "GA4 চালু" অন করুন। Measurement ID খালি রাখলে Firebase-এর অটো আইডি (measurementId) ব্যবহার হবে; নিজের GA4 প্রপার্টির `G-XXXXXXXXXX` দিতে পারেন।
- **Facebook Pixel:** Meta Events Manager থেকে Pixel ID নিয়ে দিন।
- **অটো-ট্র্যাক হওয়া ইভেন্ট:** page_view, view_item (পণ্য দেখা), add_to_cart, begin_checkout, purchase (অর্ডার সফল), search।
- বিজ্ঞাপন চালানোর আগে এই ইভেন্টগুলোই কাজে লাগবে (রিমার্কেটিং অডিয়েন্স)।

## ৩. PWA + পুশ নোটিফিকেশন 🔔

**অ্যাডমিন → ইন্টিগ্রেশন → পুশ নোটিফিকেশন**

1. Firebase Console → প্রজেক্ট সেটিংস → **Cloud Messaging** → **Web Push certificates** → *Generate key pair* → public key কপি করুন
2. সেই key "VAPID Public Key" ফিল্ডে দিন → সেভ → "পুশ চালু" অন
3. কাস্টমার সাইটে ঢুকলেই নোটিফিকেশন পারমিশন চাইবে — দিলে ডিভাইস রেজিস্টার হবে (প্যানেলে ডিভাইস সংখ্যা দেখাবে)
4. "টেস্ট নোটিফিকেশন" বাটনে চেক করুন

**PWA:** কাস্টমার Chrome-এর "Install app" / "Add to Home screen" দিয়ে সাইটটি অ্যাপের মতো ইনস্টল করতে পারবে — অফলাইনেও আগে দেখা পেজ খুলবে। আলাদা কিছু করতে হবে না।

## ৪. SMS নোটিফিকেশন (কাস্টম প্রোভাইডার) 📱

**অ্যাডমিন → ইন্টিগ্রেশন → SMS নোটিফিকেশন**

**সমর্থিত প্রোভাইডার (৩টি):**

| প্রোভাইডার | যা দিতে হবে |
|---|---|
| **Bulk SMS BD** (bulksmsbd.net) | API Key + Sender ID |
| **SSL Wireless** | Store ID (SID) + Store Password (API Token) |
| **কাস্টম API** | API URL + Method (GET/POST) + Body টেমপ্লেট (`{apikey}` `{to}` `{message}` `{sender}`) — যেকোনো বাংলাদেশি প্রোভাইডার বসবে |

**টেমপ্লেট ভেরিয়েবল:** `{name}` `{order}` `{total}` `{status}` `{site}` `{count}` `{offer}`

- নতুন অর্ডারে কাস্টমারকে অটো SMS + ঐচ্ছিকভাবে আপনাকে (অ্যাডমিন নম্বর দিলে)
- স্ট্যাটাস পরিবর্তনে (কনফার্মড/শিপড/ডেলিভার্ড...) অটো SMS
- "টেস্ট SMS" দিয়ে সেভের পরে যাচাই করুন
- সব SMS-এর লগ প্যানেলেই দেখা যাবে (সফল/ব্যর্থ)

> SMS পাঠানো হয় আপনার নিজের সার্ভারের API রুট দিয়ে (`/api/sms/send`) — API কী কখনো ব্রাউজারে যায় না। প্রতি নম্বরে মিনিটে ৬টির বেশি SMS গেলে স্প্যাম-রক্ষা ব্লক করে।

## ৫. কুরিয়ার — Steadfast (এক ক্লিকে কনসাইনমেন্ট) 🚚

**অ্যাডমিন → ইন্টিগ্রেশন → কুরিয়ার (Steadfast)**

1. portal.steadfast.com.bd → Settings → **API** থেকে API Key + Secret Key নিন
2. এখানে দিয়ে সেভ করুন → "Steadfast ইন্টিগ্রেশন চালু" অন
3. "ব্যালেন্স দেখুন" দিয়ে যাচাই করুন
4. **ব্যবহার:** অ্যাডমিন → অর্ডার ও রিটার্ন → অর্ডার খুলুন → **"Steadfast-এ পাঠান"** বাটন → কনসাইনমেন্ট তৈরি হয়ে ট্র্যাকিং নম্বর অর্ডারে সেভ হয়ে যাবে (স্ট্যাটাস অটো SHIPPED)
5. অপরিশোধিত অর্ডারে COD amount পাঠানো হয় (সেটিং দিয়ে বদলানো যায়)

## ৬. পেমেন্ট গেটওয়ে — bKash / SSLCommerz / কাস্টম 💳

**অ্যাডমিন → ইন্টিগ্রেশন → পেমেন্ট গেটওয়ে**

### bKash Tokenized Checkout
1. bKash মার্চেন্ট অ্যাকাউন্ট (tokenized) থেকে Username, Password, App Key, App Secret নিন
2. চালু করুন → মোড দিন (প্রথমে **Sandbox** টেস্ট করুন, পরে Live)
3. চেকআউটে নতুন মেথড দেখাবে: **bKash (অনলাইন পেমেন্ট)** — কাস্টমার bKash পেজে গিয়ে পেমেন্ট করলে অর্ডার **অটো PAID** হয়ে যাবে (TrxID ম্যানুয়াল ম্যাচিং শেষ!)

### SSLCommerz
1. merchant.sslcommerz.com থেকে Store ID + Store Password নিন
2. চালু করুন → চেকআউটে **"কার্ড / অনলাইন পেমেন্ট (SSLCommerz)"** — Visa/Mastercard, নেট ব্যাংকিং, মোবাইল ব্যাংকিং সব একসাথে
3. পেমেন্ট ভেরিফাই সার্ভারেই হয় (validation API) — ভুয়া success বাতিল হয়ে যায়

### কাস্টম পেমেন্ট গেটওয়ে
- **"নতুন গেটওয়ে"** বাটনে যেকোনো ম্যানুয়াল পেমেন্ট যোগ করুন: নাম + লোগো + অ্যাকাউন্ট নম্বর + নির্দেশনা + TrxID লাগবে কিনা
- চেকআউটে বিল্ট-ইন মেথডের পাশেই দেখাবে

> ⚠️ গেটওয়ে কলব্যাক সঠিকভাবে ফিরতে হোস্টিং Environment Variable-এ **`NEXT_PUBLIC_SITE_URL=https://আপনার-ডোমেইন.com`** অবশ্যই দিতে হবে।

## ৭. লয়ালটি পয়েন্ট ⭐

**অ্যাডমিন → গ্রোথ ও রিটেনশন → লয়ালটি পয়েন্ট**

- চালু করুন + রেট ঠিক করুন: প্রতি ১০০৳-এ কত পয়েন্ট (ডিফল্ট ১), ১ পয়েন্ট = কত টাকা (ডিফল্ট ৳১), অর্ডারের সর্বোচ্চ কত % পয়েন্টে দেওয়া যাবে (ডিফল্ট ৫০%)
- **অর্জন:** অর্ডার DELIVERED হলে অটো পয়েন্ট
- **খরচ:** চেকআউটে "লয়ালটি পয়েন্ট ব্যবহার করুন" বক্স — কাস্টমার সরাসরি ছাড় নেবে
- কাস্টমার তার ব্যালেন্স ও হিস্ট্রি দেখবে অ্যাকাউন্ট → লয়ালটি পয়েন্ট ট্যাবে
- অ্যাডমিন যেকোনো কাস্টমারের পয়েন্ট +/- করতে পারবেন (কারণ লিখে)

## ৮. রেফারেল কমিশন 💰

**অ্যাডমিন → গ্রোথ ও রিটেনশন → রেফারেল কমিশন**

- চালু করুন → কমিশন % (ডিফল্ট ৫%) → সর্বনিম্ন তোলা (ডিফল্ট ৳৫০০)
- বিকল্প: শুধু রেফার করা ক্রেতার **প্রথম** অর্ডারে কমিশন (ডিফল্ট অন) — বন্ধ করলে সব অর্ডারে
- **কাজের ধরন:** কাস্টমার অ্যাকাউন্ট → "রেফারেল আয়" ট্যাবে নিজের কোড (TSB-XXXXXX) + শেয়ার লিংক পাবে; বন্ধু ওই লিংক থেকে রেজিস্টার করলে (`?ref=CODE`) অ্যাট্রিবিউট হয়; বন্ধুর অর্ডার ডেলিভারি হলে কমিশন ক্রেডিট
- কাস্টমার টাকা তুলতে আবেদন করবে → অ্যাডমিন প্যানেলে **পরিশোধ/বাতিল** করবেন
- টপ রেফারার তালিকা প্যানেলে দেখা যায়

## ৯. অ্যাব্যান্ডন্ড কার্ট রিমাইন্ডার 🛒

**অ্যাডমিন → গ্রোথ ও রিটেনশন → অ্যাব্যান্ডন্ড কার্ট**

- ট্র্যাকিং চালু করুন → কত মিনিট পরে "অ্যাব্যান্ডন্ড" ধরা হবে (ডিফল্ট ৬০)
- তালিকায় প্রতিটি কার্ট দেখাবে (পণ্য, মূল্য, ফোন) → **SMS** বা **WhatsApp** দিয়ে ম্যানুয়াল রিমাইন্ডার
- **অটো-রিমাইন্ডার (ঐচ্ছিক):** cron-job.org-এ ফ্রি অ্যাকাউন্ট খুলে জব বানান:
  - URL: `https://আপনার-ডোমেইন.com/api/cron/abandoned?secret=<ওয়েবহুক-সিক্রেট>`
  - সিক্রেট: সেটিংসের `webhook_secret` (ডিফল্ট `tsb-hook-change-me` — নিরাপত্তার জন্য বদলে ফেলুন)
  - Schedule: প্রতি ঘণ্টায়
- SMS টেমপ্লেট: SMS সেকশনে "অ্যাব্যান্ডন্ড কার্ট রিমাইন্ডার" + অফার লাইন

## ১০. রিভিউতে ছবি 📸

আলাদা সেটআপ লাগে না — কাস্টমার এখন রিভিউর সাথে **৩টি পর্যন্ত ছবি** দিতে পারবে।

- ছবি আপলোড হয় আপনার **GitHub হোস্টিং** কনফিগ থাকলে (অ্যাডমিন → সেটিংস → GitHub হোস্টিং) — নইলে সাময়িক dataURL
- ছবিসহ রিভিউ মডারেশনে দেখা যাবে (অ্যাডমিন → রিভিউ মডারেশন)
- পণ্য পেজে থাম্বনেইল + ক্লিকে বড় লাইটবক্স

## নতুন অ্যাডমিন মেনু ম্যাপ

```
অ্যাডমিন প্যানেল
├── ওভারভিউ: ড্যাশবোর্ড
├── ক্যাটালগ: পণ্য / ক্যাটাগরি / ব্র্যান্ড
├── বিক্রয়: অর্ডার ও রিটার্ন / পেমেন্ট / কাস্টমার
├── 🆕 গ্রোথ ও রিটেনশন: লয়ালটি / রেফারেল / অ্যাব্যান্ডন্ড কার্ট
├── মার্কেটিং: কুপন / মার্কেটিং টুলস / হোমপেজ কনটেন্ট
├── 🆕 ইন্টিগ্রেশন: WhatsApp / SMS / কুরিয়ার / গেটওয়ে / GA4-পিক্সেল / পুশ
├── সাপোর্ট: রিভিউ / সাবস্ক্রাইবার
└── সিস্টেম: ডেলিভারি / CMS / রোল / রিপোর্ট / সেটিংস / ব্যাকআপ
```

অ্যাডমিন মেনু (সাইডবার + মোবাইল ড্রয়ার) নতুন করে ডিজাইন করা হয়েছে — গ্রুপ হেডার, অ্যাকটিভ ইন্ডিকেটর, হোভার অ্যানিমেশন, মোবাইলে স্মুথ ড্রয়ার।
