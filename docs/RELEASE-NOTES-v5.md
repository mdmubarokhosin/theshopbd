# RELEASE NOTES — v5

## 🎯 পার্ক বক্স (Perk Boxes) — bdeasyshop.com হুবহু ডিজাইন + সম্পূর্ণ রেসপন্সিভ ফিট

পণ্য পেজের ট্রাস্ট ব্যাজ (দ্রুত ডেলিভারি • ১০০% অরিজিনাল • সহজ রিটার্ন) এখন
**bdeasyshop.com-এর অফিসিয়াল `.perk-boxes` ডিজাইনের হুবহু রেপ্লিকা** — তাদের
প্রকাশিত CSS থেকে প্রতিটি মান (বর্ডার, গ্রেডিয়েন্ট, শ্যাডো, ফন্ট, ব্রেকপয়েন্ট)
হুবহু নেওয়া হয়েছে। মোবাইলে আর **কোনো হরাইজন্টাল স্ক্রল নেই** — সম্পূর্ণ
স্ক্রিনে ফিট হয়।

## ১) হুবহু ডিজাইন (রেফারেন্স CSS থেকে)

| উপাদান (মোবাইল ≤৮৬০px) | মান |
|---|---|
| লেআউট | ৩-কলাম গ্রিড, রো বক্স (আইকন বামে) |
| বর্ডার | `1px solid #fbd5b5` (উষ্ণ পিচ) |
| কর্নার রেডিয়াস | ১০px |
| শ্যাডো | `0 6px 18px rgba(244,124,0,.08)` |
| আইকন সার্কেল | ৩৪px, `radial-gradient(#fff4ea → #ffe4cc)` |
| আইকন কালার | `#ed7b00` (bdeasyshop ব্র্যান্ড অরেঞ্জ) |
| আইকন শ্যাডো | `0 3px 10px rgba(244,124,0,.15)` |
| টাইটেল | ১২.৫px, bold, `#111827` |
| সাবটাইটেল | ১১px, `#6b7280` |

### ছোট মোবাইল (≤৬০০px) — রেফারেন্সের কমপ্যাক্ট টিয়ার

- গ্যাপ ৩px, প্যাডিং ৭px×৩px, আইকন সার্কেল ২২px, আইকন ১৩px
- ফন্ট clamp স্কেলিং: টাইটেল `clamp(7px, 2.2vw, 10.5px)`, সাবটাইটেল `clamp(6px, 1.95vw, 9px)`

### ট্যাবলেট (৭৬৮–১২৭৯px) — স্ট্যাকড

- এক কলামে স্ট্যাক, কলাম বক্স (আইকন উপরে সেন্টারে)
- প্লেইন আইকন ৪২px (সার্কেল নেই), টাইটেল ১৪px, সাবটাইটেল ১২.৫px
- বর্ডার `#e9ecef`, প্যাডিং ১০px×১৪px

### ডেস্কটপ (≥১২৮০px) — রেফারেন্স বেস ডিজাইন

- ৩-কলাম, কলাম বক্স সেন্টারড (আইকন উপরে → টাইটেল → সাবটাইটেল)
- প্লেইন আইকন ২০px, টাইটেল ১৩px, সাবটাইটেল ১১px
- বর্ডার `#e9ecef`, রেডিয়াস ৮px, প্যাডিং ১৪px×৮px, গ্যাপ ১০px

## ২) রেসপন্সিভ ফিট — প্রমাণসহ

প্রতিটি ব্রেকপয়েন্টে `scrollWidth == clientWidth` যাচাই করা হয়েছে
(অর্থাৎ **শূন্য হরাইজন্টাল ওভারফ্লো**):

| ভিউপোর্ট | ফলাফল |
|---|---|
| ৩৭৫px (মোবাইল) | ✅ ৩৭৫ = ৩৭৫ — পার্ফেক্ট ফিট |
| ৬০০px | ✅ ৬০০ = ৬০০ |
| ৭৬৮px | ✅ ৭৬৮ = ৭৬৮ |
| ৮২০px (ট্যাবলেট) | ✅ ৮২০ = ৮২০ |
| ১৩৬৬px (ডেস্কটপ) | ✅ ১৩৬৬ = ১৩৬৬ |

- Tailwind গ্রিড `minmax(0,1fr)` + `min-w-0` + `truncate` — অ্যাডমিন যত লম্বা
  টাইটেলই দিক, কখনোই পেজ ওভারফ্লো হবে না (শুধু … দেখাবে)
- ডার্ক মোড: উষ্ণ বর্ডার ২০% অ্যালফায়, বক্স `card` ব্যাকগ্রাউন্ডে অ্যাডাপ্ট করে

## ৩) বোনাস ফিক্স — ট্যাবলেট ওভারফ্লো (বাটন রো)
