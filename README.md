# THE SHOP BD 🛍️

বাংলাদেশের একটি সম্পূর্ণ **মাল্টিব্র্যান্ড ই-কমার্স প্ল্যাটফর্ম** — কাস্টমার শপ + পূর্ণাঙ্গ অ্যাডমিন প্যানেল, সম্পূর্ণ বাংলা ভাষায়। ডিফল্ট ব্র্যান্ড **THE SHOP BD** — অ্যাডমিন প্যানেল → ওয়েবসাইট সেটিংস থেকে যেকোনো সময় পরিবর্তনযোগ্য (নাম, ট্যাগলাইন, লোগো, ফেভিকন সবই ডায়নামিক)।

## ✨ বৈশিষ্ট্যসমূহ

### 🛒 কাস্টমার প্যানেল
- আধুনিক হোমপেজ: হিরো স্লাইডার, অফার ব্যানার, ক্যাটাগরি, ব্র্যান্ড লোগো, ফ্ল্যাশ সেল, রিভিউ
- অ্যাকাউন্ট: **Google Sign-in** (প্রোফাইল অটো-ফিল), ইমেইল+পাসওয়ার্ড রেজিস্ট্রেশন/লগইন, রিয়েল পাসওয়ার্ড রিসেট ইমেইল (Firebase Auth), প্রোফাইল
- পণ্য: সার্চ + সাজেশন, ফিল্টার (ক্যাটাগরি/ব্র্যান্ড/দাম/রেটিং/স্টক), সর্টিং, ভ্যারিয়েন্ট (রং/সাইজ)
- ডেডিকেটেড **সার্চ পেজ** (`/search`): রিয়েল-টাইম ফলাফল (টাইপ করার সাথে সাথে), সাম্প্রতিক সার্চ, জনপ্রিয় কিওয়ার্ড, শেয়ারযোগ্য URL (?q=)
- কার্ট: গেস্ট কার্ট, লগইনে অটো-মার্জ, কুপন, ফ্রি শিপিং
- চেকআউট: সেভ করা ঠিকানা, ডেলিভারি জোন অনুযায়ী চার্জ, bKash/Nagad/Rocket (TrxID সহ), COD, কার্ড
- অর্ডার: ট্র্যাকিং টাইমলাইন, ইনভয়েস প্রিন্ট, বাতিল/রিটার্ন/রিপ্লেসমেন্ট অনুরোধ, রিঅর্ডার
- ড্যাশবোর্ড: অর্ডার, ঠিকানা, নোটিফিকেশন, সাপোর্ট টিকেট, রিভিউ, নিরাপত্তা
- উইশলিস্ট, প্রোডাক্ট তুলনা, সাম্প্রতিক দেখা পণ্য

### 🛠️ অ্যাডমিন প্যানেল (A to Z)
- **ড্যাশবোর্ড**: বিক্রয়/অর্ডার/কাস্টমার/স্টক KPI, ১৪-দিনের **Chart.js** চার্ট, টপ প্রোডাক্ট, পেমেন্ট ব্রেকডাউন
- **ক্যাটালগ**: পণ্য (ভ্যারিয়েন্ট ম্যাট্রিক্স, বাল্ক CSV ইমপোর্ট/এক্সপোর্ট, ডুপ্লিকেট), ক্যাটাগরি (ইমেজ+আইকন+রং), ব্র্যান্ড (লোগো)
- **বিক্রয়**: অর্ডার (স্ট্যাটাস ট্রানজিশন ভ্যালিডেশন, কুরিয়ার+ট্র্যাকিং, ইনভয়েস, রিফান্ড), রিটার্ন রিভিউ, পেমেন্ট মেথড + ট্রানজেকশন ভেরিফিকেশন, কাস্টমার (গ্রুপ/সাসপেন্ড)
- **মার্কেটিং**: হিরো স্লাইড, সাইড ব্যানার, ফ্ল্যাশ সেল, কুপন, ঘোষণা বার, পপআপ নোটিশ/অফার (টেক্সট/ইমেজ), ব্রডকাস্ট নোটিফিকেশন
- **CMS**: সব পেজ (আমাদের সম্পর্কে, FAQ, পলিসি...) এডিটযোগ্য, নতুন পেজ তৈরি
- **সিস্টেম**: রোল-ভিত্তিক পারমিশন (RBAC) + স্টাফ অ্যাকাউন্ট, ডেলিভারি জোন/কুরিয়ার, স্টক মুভমেন্ট, রিপোর্ট (৯ ধরনের + CSV), খরচ ও লাভ-ক্ষতি, অডিট লগ, ব্যাকআপ/রিস্টোর (JSON), মিডিয়া লাইব্রেরি, সেটিংস (সাধারণ/লোকালাইজেশন/ট্যাক্স/নোটিফিকেশন/SEO/নিরাপত্তা)

## 🔗 পেজ URL স্ট্রাকচার (প্রতিটি পেজের নিজস্ব লিংক)

```
/                        → হোম

/wishlist                → উইশলিস্ট
/compare                 → পণ্য তুলনা
/login                   → লগইন/রেজিস্ট্রেশন (?mode=register)
```

### 📱 Termux / Android-এ চালানো

কোনো অতিরিক্ত কিছু করতে হয় না — **`npm install && npm run dev` একই কমান্ড** সব প্ল্যাটফর্মে কাজ করে:

```bash
pkg install nodejs git   # Termux-এ প্রথমবার হলে
npm install
npm run dev
```

**কেন কাজ করে?** `scripts/next-runner.mjs` নামে একটি স্মার্ট লঞ্চার আছে। Next.js 16-এর ডিফল্ট বান্ডলার **Turbopack**-এর নেটিভ বাইন্ডিং Android (android/arm64)-তে নেই — এরর আসে: `Turbopack is not supported on this platform (android/arm64)`। লঞ্চারটি Termux/Android শনাক্ত করলে **স্বয়ংক্রিয়ভাবে `--webpack` মোডে** চালায় (আপনার কিছু করার নেই)।

Termux-এ নোট করুন:
- প্রথম পেজ লোডে কম্পাইলে **১–৩ মিনিট** লাগতে পারে (WASM ব্যবহার হয়) — এটা স্বাভাবিক, পরেরবার দ্রুত হবে
- ব্রাউজার ট্যাব কম রাখুন, ফোনে RAM খালি রাখুন
- পোর্ট বদলাতে চাইলে: `npm run dev -- -p 3001`
- জোর করে বান্ডলার বদলাতে: `TSB_BUNDLER=webpack npm run dev` (বা `turbopack`)

> 💡 প্রজেক্টে ইচ্ছাকৃতভাবে Google Fonts (`next/font`) ব্যবহার করা হয়নি — কম্পাইল-টাইমে ফন্ট ডাউনলোডের ঝুঁকি এড়াতে। বাংলা টেক্সট সিস্টেম ফন্টেই সুন্দর দেখায়।

## ☁️ Firebase — ডেটা কোথায় থাকে?

সব ডেটা **Firebase Realtime Database**-এর `shop` নোডে থাকে (Firestore ব্যবহার হয় না) — পণ্য, অর্ডার, কাস্টমার, সেটিংস সবকিছু রিয়েল-টাইমে সব ডিভাইসে সিঙ্ক হয়। ব্রাউজারে অফলাইন-ফার্স্ট localStorage মিরর থাকে, তাই ইন্টারনেট না থাকলেও সাইট চলে।

- **ইউজার অথ**: Firebase Authentication (Google + Email/Password)
- **মিডিয়া হোস্টিং**: GitHub রিপো API (Contents) → jsDelivr CDN দিয়ে লোড — সেটআপ: অ্যাডমিন → সেটিংস → **GitHub হোস্টিং** ট্যাব
- **ব্যাকআপ**: অ্যাডমিন → ব্যাকআপ ও সিস্টেম → JSON ডাউনলোড/ইমপোর্ট (পুরো RTDB ডেটা)
- **রিসেট**: অ্যাডমিন → ব্যাকআপ ও সিস্টেম → ফ্যাক্টরি রিসেট (RTDB-তেও ডিফল্ট ডেটা ফিরে যায়)

বিস্তারিত সেটআপ গাইড: **[docs/FIREBASE-SETUP.md](docs/FIREBASE-SETUP.md)**

## 🧩 ডেটা লেয়ার আর্কিটেকচার

```
src/lib/
├── firebase/app.ts   ← Firebase কনফিগ + Auth/RTDB ইনিট (এখানেই কনফিগ বদলাবেন)
└── db/
    ├── cloud.ts      ← RTDB ↔ localStorage সিঙ্ক ইঞ্জিন (সোর্স অব ট্রুথ = RTDB)
    ├── core.ts       ← লোকাল মিরর ইঞ্জিন (সিঙ্ক্রোনাস রিড/রাইট, React-safe)
    ├── services.ts   ← সব বিজনেস লজিক (REST API-র সাথে ১:১ সিগনেচার)
    ├── auth.ts       ← Firebase Auth ব্রিজ (Google/Email/অ্যাডমিন বুটস্ট্র্যাপ/RBAC)
    ├── github.ts     ← GitHub রিপো হোস্টিং (আপলোড + jsDelivr URL + সংযোগ পরীক্ষা)
    ├── hooks.ts      ← React বাইন্ডিং (useSyncExternalStore)
    ├── seed-data.ts  ← প্রথম রানের ডিফল্ট ডেটা (RTDB ফাঁকা হলে অটো-বুটস্ট্র্যাপ)
    └── types.ts      ← সব এন্টিটির টাইপ
```
